# Writing Your First Test

In this second module, we will dive right into the code and write our first test. 

Playwright uses locators to find elements on the page.

## Hands-on

1. Open `tests/example.spec.ts`.
2. Add a `test('basic test')`.
3. Use `page.goto()` and `page.getByRole()`.
