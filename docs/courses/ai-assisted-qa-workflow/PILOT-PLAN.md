# AI-Assisted QA Workflow — Private Pilot Plan

## Pilot boundary

This pilot validates the learner flow, local setup, QA reasoning, and AI-assisted workflow before broader promotion. It does not validate monetization, CI, or a larger QA curriculum.

**Audience:** 5–10 Manual QA professionals transitioning to automation.
**Course access:** All seven checkpoints available from day one.
**Execution:** Learner-owned machine and companion repository.
**Feedback:** Optional private repository review after the learner completes the full course.

## Success criteria

- At least 5 learners participate.
- At least 4 successfully install the starter repository and run the first local test.
- At least 3 complete all seven checkpoints and the capstone.
- Most completers correctly classify the seeded failure.
- Learners report that AI improved their workflow rather than only helping them write prompts.
- No critical safety, privacy, target, or data-handling issue is found.

## Pilot workflow

1. Invite a small group privately.
2. Give every learner the course overview link and starter-template link.
3. Ask learners to complete the course at their own pace.
4. Track setup success, checkpoint completion, abandonment, and friction.
5. Invite completed learners to contact the course owner privately for optional repository review.
6. Review the full repository once using the private AI-assisted reviewer workspace.
7. Send final feedback manually.
8. Offer one follow-up review after revision.

## Do not collect

- Credentials or tokens
- Real booking data
- Private calendar information
- Full repository uploads
- Unnecessary personal information

## Pilot decision questions

- Where do learners stop or become uncertain?
- Which checkpoint produces the strongest evidence of QA reasoning?
- Does the local starter repository work reliably enough across operating systems?
- Does the seeded failure lead to correct classification?
- Which AI suggestions are useful, misleading, or difficult to verify?
- Is the course ready for public release without adding more platform features?
