# Acceptance criteria

These criteria are fictional course practice requirements. They are not the vendor's actual specification.

- **AC-01:** The event page shows the event name and at least one available scheduling option when availability exists.
- **AC-02:** A learner can select one available date and time.
- **AC-03:** The selected date, time, and timezone remain visible before submission.
- **AC-04:** Name and email are required before the pre-submission summary can be reached.
- **AC-05:** An invalid email format produces an observable validation message and does not advance the flow.
- **AC-06:** Optional notes do not block the pre-submission summary when empty.
- **AC-07:** The pre-submission summary shows the selected slot and entered synthetic contact details.
- **AC-08:** The course exercise stops before final booking submission.
