# Artifact map

Keep artifacts small, sanitized, and connected to the checkpoint that produced them.

- `requirements/` — PRD notes, assumptions, ambiguity, and risks.
- `test-cases/` — scenarios, cases, priorities, traceability, and automation candidates.
- `reports/` — execution, failure analysis, defect communication, and quality summary.
- `../evidence/` — sanitized screenshots, traces, logs, and links to reports.
- `../reflections/` — checkpoint and capstone reflections.
