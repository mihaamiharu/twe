# Evidence rules

Store sanitized evidence here or link to reports under `docs/reports/`.

- Keep the original failure evidence before changing code.
- Remove names, email addresses, tokens, invitee data, and private URLs.
- Use descriptive filenames such as `tc-001-pass.png` or `triage-initial-output.txt`.
- Do not commit full browser profiles, `.env`, or uncontrolled recordings.
